# wikidot-skill
让Agent理解如何使用和检查Wikidot语法的Skill

## 使用
如果你正在使用Codex、Claude Code、Deepseek Harness、WorkBuddy、豆包工作等Agent应用，创建一个新对话发送如下消息安装：
```md
https://github.com/whiteluw/wikidot-skill 安装此Skill
```

如果你正在使用Deepseek网页版/App等即时问答类AI App，每个会话提问前面加上：
```md
https://github.com/whiteluw/wikidot-skill/blob/main/SKILL.md
根据这一Skills，解答我的问题：
在这里放你的问题
```
